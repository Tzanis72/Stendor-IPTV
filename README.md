# Stendor IPTV

Κατάλογοι για την εφαρμογή **IptvSimple** (Android). Ενημερώνονται αυτόματα από το GitHub Actions.

| Αρχείο | Τι είναι | Ενημέρωση |
|---|---|---|
| `gr.m3u` | Live κανάλια (iptv-org + `extra.m3u`) | κάθε 6 ώρες |
| `catalog/index.json` | Λίστα καναλιών με σειρές | κάθε μέρα |
| `catalog/<κανάλι>.json` | Εκπομπές & επεισόδια ανά κανάλι | κάθε μέρα |

- Δικά σου κανάλια: πρόσθεσέ τα στο `extra.m3u`.
- Χειροκίνητη ενημέρωση: tab **Actions** → διάλεξε workflow → **Run workflow**.
- Αν μια πηγή χαλάσει, κρατιέται αυτόματα η τελευταία καλή έκδοση.
- Νέα κανάλια σειρών: `scripts/build.py` → λίστα `CHANNELS`.

Όλο το περιεχόμενο προέρχεται από τις επίσημες, δωρεάν πηγές των καναλιών. Το repository δεν αποθηκεύει βίντεο, μόνο διευθύνσεις.
